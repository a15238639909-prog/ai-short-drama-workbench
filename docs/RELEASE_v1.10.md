# v1.10 完整版更新说明

日期：2026-11-01。对照版本为2026-10-23发布的 v1.09。公开包包含工作台程序、通用预设、工作流及接入文档，模型权重和运行环境需另行准备。

## 生图与本地写词

- MOSS 加入出图词与主流程，独立使用本地 Qwen 编写中文画面或规划布局，不再直接复用 Krea2 指令。
- 主流程的人物、场景分别选择 Krea2/MOSS。MOSS 支持2倍（1360×768→2720×1536）与4K（1920×1088→3840×2176）双阶段输出。
- Krea2、MOSS、Anima 可混合加入待生产列表，各项保存模型、提示词、比例、尺寸和种子，按顺序生成。当前列表是页面内存，刷新会丢失；历史记录与列表不是同一功能。
- Anima 提供常规单图、人设图两个入口，按需求加载短规则模块，固定质量前缀由程序拼接，画师下拉共9项。包内附作品/人物名字库，只含身份名称和触发词，不含外貌或图片；中文别名覆盖有限。来源与范围见[名字库说明](ANIMA_CATALOG_SOURCE.md)。

## 长篇漫画与编辑

- 新增独立漫画项目：本地 Qwen 规划章节、页面、分格和中文对白，MOSS 按页生成整页漫画。
- 可从主项目复制文字人设，保留独立来源快照；按格维护穿戴、持物、伤势和位置。跨页衔接依据是已保存叙事状态，不是自动看图后确认的事实。
- 支持暂停续作、单页修改/重做、历史版本采用、ZIP/PDF导出。过期规划、已改未重做页面和无效图片不会冒充当前完成版本导出。
- 可选 Qwen Image 2.1：上传人物参考，在当前采用页框选局部，生成候选、预览比较后手动采用。框外原图像素保留；选区内部仍需检查身份、画风和接缝。编辑模型与节点单独配置，MOSS整页生成功能不依赖它。

## 视频文字与场景

- 精简重复的人设章节、穿戴规则与道具描述；模型提示词使用正向可见内容，规则与有限检查留在后台。
- 改进源剧情中的穿脱、换装、持物交接、安放和多人指代；增加已完成动作的重复检查。源剧情计划与实际画面观察保持区分，不能用计划冒充已经拍成。
- 场景底图采用开场固定空间，清理未获原始要求支持的湿痕床品、散落衣物等后续痕迹；默认自然整洁，明确要求的暗光、杂乱、烧焦等状态保留并检查遗漏。
- 自动缓存提示词按当前规则重新校验；手写覆盖、已经采用的素材和冻结提交请求继续保留。旧图片、旧视频不会因为更新代码自动变化。

## 保存与恢复

改善旧页面覆盖后台新结果、保存期间连续输入/切项目导致提交旧文字、多场景实际段号、过期错误提醒及漫画已出图后复制失败而重复生成等问题。任务仍需按实际状态决定继续、重做或暂停，更新不会将所有失败自动转成成功。

## 下载与接入

下载 `v1.10-complete-20261101-source.zip` 并解压。先读根目录[AI接入说明](../AI接入说明.md)和[本地模型接入详解](LOCAL_MODEL_INTEGRATION.md)，可将整个目录交给能够读取本地文件的AI工具协助配置已有模型服务。

公开包不包含作者个人配置、私人项目、媒体、日志、模型或推理环境。先备份自己的配置、项目、素材和私人预设，在新目录验证；不能用公开包覆盖整套旧安装数据。需要的模型、ComfyUI节点及协议以实际客户端和工作流为准。

## 验证与限制

本次独立公开副本的语法、公开文件范围、凭据扫描和定向无模型检查结果见[RELEASE_v1.10_CHECKS.json](RELEASE_v1.10_CHECKS.json)。以本次记录为准，不累计历史重复检查，也不将模拟通过解释为新电脑模型已接通或所有视觉效果通过。

真实生成仍可能有人脸、服装、动作、道具、场景细节、漫画中文字及音画对应问题。原版H3、当前工作流与加速模型的讨论不等于本次更换了视频模型。本版不承诺锁脸、逐帧无误差、零错字或无缝长片。

## 回滚

旧标签和旧发布保留。回滚程序时保留后来新增的项目、素材、配置与预设，不用旧包替换整套数据。先在无活动、排队和待恢复任务时处理程序更新或回滚。
