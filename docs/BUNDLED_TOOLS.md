# 五个内置工具使用说明

v1.03将问AI、虚拟人物、出图词、动作迁移和视频导演台一起放入源码包。同一个工作台左侧即可进入，不需要另开旧服务。代码和默认模板已经包含，模型权重和用户私人数据没有包含。

## 每个板块做什么

| 板块 | 使用方式 | 需要的本地环境 |
| --- | --- | --- |
| 问AI | 输入问题，与本地模型对话，保存和读取聊天；可修改对话设定 | 8080上的兼容Qwen服务 |
| 虚拟人物 | 新建角色、填写或修改人物资料，与角色对话；按需生成图片 | 文字功能用Qwen，图片功能用ComfyUI |
| 出图词 | 选择Krea2或Anima及对应预设，生成或手写提示词，再出图 | Qwen编写提示词，ComfyUI执行对应工作流 |
| 动作迁移 | 上传原片、人物和可选场景，填写特征，自动分段替换并拼合 | H3、FFmpeg、ffprobe；默认10步 |
| 视频导演台 | 选择文生、首帧、首尾帧或多素材参考，整理提示词再生成视频 | Qwen与H3；附带通用视频提示词模板 |

出图词中两个模型的预设、编辑框草稿分别管理。Anima仅是手动快速出图工具，不接管自动故事制作。三视图和面部特写是提示词要求，不保证每次图片都严格符合，仍需人工检查。

## 配置一次共同使用

按根目录`config.example.json`创建自己的`config.json`，设置文字模型、投影模型、ComfyUI和H3路径。内置工具共用`llama_server_exe`、`model_gguf`、`mmproj_gguf`、`comfy_dir`、`comfy_output`和`h3_root`；`legacy_root`留空。

自动启动ComfyUI使用整合包结构：`comfy_dir/python/python.exe`和`comfy_dir/ComfyUI/main.py`。H3同样使用`h3_root/python/python.exe`和`h3_root/ComfyUI/main.py`。如果目录结构不同，可先自行启动兼容服务：文字8080、图片8188、H3视频8190。工作流要求的模型文件和节点仍须匹配。

工具中的快速视觉为可选功能，需要额外的Qwen2.5-VL模型及投影文件；可在`config.json`增加`q25_model_gguf`、`q25_mmproj_gguf`，或自行提供8081兼容服务。未配置时普通文字对话和手写提示词出图不依赖此分支。代码不会替用户下载模型。

配置文件修改后重启工作台。未配置的模型会在使用对应功能时报错，不代表代码包中缺少该页面。模型切换可能释放其他模型显存，请勿同时运行重要推理任务。

## 数据保存位置

以下路径均相对于工作台根目录，运行时自动创建，发布源码中不带作者数据。

| 内容 | 目录或文件 |
| --- | --- |
| 问AI聊天和对话设定 | `_legacy_8848/chats/`、`_legacy_8848/chat_persona.txt` |
| 虚拟人物资料与聊天 | `_legacy_8848/virtual_characters/` |
| 出图词自定义预设 | `_legacy_8848/presets/`，按krea2和anima分组 |
| Anima共用默认指令 | `presets/instructions/Anima_英文词组.txt`、`Anima_人物三视图.txt` |
| 视频导演台预设、提示词存档和成品 | `_legacy_8848/video-presets/`、`_legacy_8848/视频提示词存档/`、`_legacy_8848/视频输出/` |
| 动作迁移上传和结果 | `outputs/motion_uploads/`、`outputs/motion/` |
| 图片模型原始输出 | 配置的`comfy_output`；部分工具另有本地归档，Anima结果在`outputs/anima/` |

更新前备份上述数据、根目录`config.json`、项目`data/`、成品`outputs/`以及改过的模板。建议新目录解压试用，不覆盖原安装。需要回退时使用旧标签的源码和自己的数据备份；GitHub不保存私人项目。
