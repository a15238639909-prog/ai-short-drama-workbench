# v1.05 完整版：验收与恢复

固定标签：`v1.05-complete-20261013`。这是2026-10-13确认保存的当前版本，包含原有工作台与内嵌工具，以及通用续话、提示词修复和任务恢复改动。

## 通用行为

- 首话和续话采用同一套正文、分镜、设定准备、提示词与合成流程。保留正文对白顺序，传递前话结束状态，不按测试故事名称设置专用分支。
- 既有角色与场景继续使用已经采用的设定图；根据当前话实际出场补充新角色、新地点。对白中仅被提及的人物不会因此创建出场设定。
- 参考图区分身份、静态环境与当前状态。前段真实末帧负责状态衔接，明确跨场段可补必要的外观参考，降低旧场景道具重新出现的风险。
- 自动提示词缺漏或格式错误只修受影响段。正确提示词和有效视频保留；提交前保存最终输入、参考与请求编号，中断后先核对请求状态再继续。
- 常见失败有限重试。合成前检查媒体有效性；合成失败保留已有成片，重生成另存版本。缺段、失败、等待和取消不会显示完成。

## 已完成的验收

在独立新建的连续故事中，真实完成三话、10段及三条成片，总时长103.320秒。最终采用版本按每秒2帧检查208张取样帧，主要故事、人物身份、服装和道具数量及归属通过本次验收。三个成片完整视频与音频解码通过。

第一话在已完成一段、下一段已提交时实际中断验收服务及模型进程；重启后复用已完成片段，核对原请求并继续到合成。第二话包含故意破坏自动提示词和模型自然漏写对白标记的情况，局部修复成功，正确段提示词哈希保持。合成重试使用真实媒体，模拟一次执行失败后实际重试成功。这三项证据性质不同，不将模拟故障写成真实服务故障。

14个相关测试模块共176项通过，覆盖正文与对白来源、设定复用、恢复检查点、请求恢复、视频衔接、媒体复用、合成完成状态和新话设定。原项目故事、设定、引用图片和影片共115项哈希保持，测试中已经采用的11项旧设定资产保持。发布包另做语法、文件范围、凭据扫描和无模型回归检查；结果保存于发布记录。

## 已知边界

每秒2帧取样不等于查看原始视频每一帧。仍可能有细节漂移，实测中另记录了约0.17秒的短暂闪图。本轮按主要故事和角色、服装、道具关系验收，没有为门型、盒扣等小差异反复生成。

音频未审听；有音轨且能解码，不能证明台词逐字正确、音色或口型同步。当前也没有全自动可靠的视觉验收，不能保证任何故事都得到相同效果。

恢复有次数上限。无法安全确认的提交状态、无效的人工提示词、无法自动补齐的配置或资料，仍可能暂停并说明原因，已完成成果保留。旧内容保护模块状态未在本次发布中修改。外部模型、服务、平台和机器环境故障不等于工作台能够无限自修复。
