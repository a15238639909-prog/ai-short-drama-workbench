# Anima 离线名字库来源

公开包随附 `data/anima_names/20261026/characters.sqlite3`，供工作台在本地查询作品名、人物名和身份触发词。它是通用静态资源，不是作者的项目数据库，也不包含图片、外观描述、聊天、生成记录、模型或访问凭据。

## 来源与许可

- 基础数据：[Laxhar/noob-wiki](https://huggingface.co/datasets/Laxhar/noob-wiki)，使用其中的 [danbooru_character.csv](https://huggingface.co/datasets/Laxhar/noob-wiki/blob/main/danbooru_character.csv)。上游数据集卡声明许可为 Apache-2.0；许可全文见 [Apache-2.0.txt](licenses/Apache-2.0.txt)。
- 资料定位参考：[AnimaDex](https://github.com/zetaneko/AnimaDex)，其代码声明为 MIT。人物与作品的少量对应关系另通过 [AnimaDex 网站](https://animadex.net/)核对。参考项目的许可说明保留于 [AnimaDex-MIT.txt](licenses/AnimaDex-MIT.txt)。本包不包含该网站的图片或站点数据库。

工作台主程序的许可证不替代第三方数据和模型各自的许可。人物、作品及其他名称用于身份查询，不表示获得相关权利方背书。

## 本包做了哪些整理

数据快照日期为 **2026-10-26**；公开衍生库整理日期为 **2026-11-01**。

- 保留 244,932 条人物记录及 10 条已核对中文别名，内容仅含人物标签、作品标签、可读名字、身份触发词和来源标识。
- 将资料整理为工作台使用的 SQLite 表，并保留人物名、作品名查询索引。
- 公开库重新构建，移除本机构建报告、绝对文件路径和验收任务信息；只保留来源、许可、日期和条数等公开元数据。
- 全部人物及别名记录按排序后的内容校验，与本地资料快照一致；公开库的完整性和外键检查通过。

没有附带原始 CSV、人物图片、网页抓取缓存或私人的验收报告。本目录之外的 `data/` 仍是使用者自己的运行数据，不应提交到公开仓库。

## 能力边界

这个快照不能等同于 AnimaDex 网站当前的全部收录。中文别名目前只覆盖少量已核对角色；其他人物主要使用完整英文名或标签查找。重名时需补充作品名。

程序以只读方式查询该库，仅把本次匹配到的人物身份交给 Qwen。名字命中并不保证生图模型准确还原角色，也不能代替最终看图确认。

更新自己的安装时，可以保留已扩充的个人名字库；不要直接用公开快照覆盖自己的资料。若该文件缺失，Anima 人物查询会明确报错，需要先恢复对应的公开资源。
