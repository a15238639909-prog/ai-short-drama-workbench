# v1.09 完整版更新说明

日期：2026-10-23。公开版本包含工作台程序、通用预设、模型工作流和接入文档；模型及其运行环境需由使用者另行准备。

## 主要更新

1. 主工作台接入原版中文多镜头导演。按剧情组织镜头、表演、动作、声音和音乐，保持原字对白与声音绑定。两个出片入口逐段写当前词、生成视频、观察真实末帧，再写下一段。原有小说、剧本、来源编辑入口不被样片专用逻辑替换。
2. 导演输入去重与容量预算。原文、分段和历史约束不再重复膨胀；根据服务实际上下文容量检查请求，无法安全容纳时报告原因，不静默裁掉原文。普通OpenAI兼容聊天接口不一定提供所需的容量及分词端点。
3. 人物参考与连续性。视线目标、面对面、同框和反打对象纳入身份参考判断；行动人数与可见身份分别处理。对白提及、记忆、画外声音或已离场人物不会仅因被提到就强行出镜。
4. 身份来源与动作状态分离。人物参考图及原文明示变化决定脸、发型、衣着；实际观察保留位置、朝向、姿势、持物与动作进度。观察编号不冒认人物编号，错误外观不作为新设定向后传播。合法换装、发型及配饰变化按故事时序继续有效。
5. 镜头矛盾检查。明确的同镜头、同主体背对与可见正脸细节冲突进入有限修复；正常转身、运镜、反射、跨镜头及不明确的多人指代保守处理，不强行改剧情。
6. AI辅助接入。根目录`AI接入说明.md`提供可交给AI工具的任务，`AGENTS.md`提供入口，`docs/LOCAL_MODEL_INTEGRATION.md`记录真实路径字段、端口、协议、目录结构、检查方法及验收要求。接的是工作台的模型客户端，不是修改Codex本身的模型设置。

## 兼容与保护

- 已完成片、旧提示词、手写词、待恢复请求与原始提交快照保留；新导演和身份规则作用于相应的新请求，不批量重写历史视频。
- 保留人物音色、场景首次进入带图、同场景后续人物参考等既有调度；第一人称及无参考路线继续走相应兼容分支。
- 新增`backups/`及`tests/.retained/`忽略规则。发布从独立的公开副本整理，不将作者工作目录的私人运行历史推到GitHub。
- 公开下载包不含`config.json`、真实项目、图片、视频、音频、日志、历史备份、模型权重或访问凭据。更新旧安装时保留自己的配置、项目、素材及私人预设，先在新目录验证。

## 验证与限制

发布副本的程序回归、语法、资源范围及凭据检查结果记录在`RELEASE_v1.09_CHECKS.json`，以实际记录为准。所有发布检查禁止模型推理，模拟测试通过不代表下载者的模型已经接通。

本次身份连续性修复另在作者本机的两个实际片段上查看全部367帧，并核对其余7段文件未改；整片音视频解码通过。私人项目与这些素材不随公开包发布。这是局部实片验收，不代表所有人物、动作、场景或模型都能取得相同结果，未以听觉审查或精确口型同步作为通过依据。

当前仍依赖特定llama.cpp兼容扩展、ComfyUI节点及Krea/Anima/H3工作流，不能只改一个URL就兼容任意模型。画面可能存在细节漂移、动作偏差、场景美术差异及短暂生成错误，仍需要人工验收。没有增加完全可靠的全自动视觉质量保证。

## 回滚

旧GitHub标签和旧发布保留。程序更新前先备份自己的安装；回滚程序时保留后来新增的配置、私人预设、项目和成品，不用旧程序包覆盖整套数据。作者本地程序恢复备份与公开下载包分开保存，私人恢复包不能当作公开安装包分发。
