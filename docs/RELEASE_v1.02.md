## 可重复执行的无模型测试

在安装依赖后，于仓库根目录执行：

```powershell
$env:V41_NO_MODEL = "1"
$env:PYTHONDONTWRITEBYTECODE = "1"
python -B -m unittest discover -s tests -p test_dialogue_timing.py -v
python -B -m unittest discover -s tests -p test_motion_anima_release.py -v
```

上述命令不会加载AI模型。日常启动工作台前，在新的终端运行，或移除本测试终端中设置的`V41_NO_MODEL`，否则模型运行会被主动禁止。

## 画面实测与边界

动作迁移此前在正式环境完成三条约14.67秒、15.25秒、23秒的完整测试。23秒素材另完成25步对照，交付原片对比和10步/25步对比；用户认为没有明显区别，默认保留10步。核验25步交付为552帧、24fps、23秒，各份交付音轨一致，保留原视频声音。

动作迁移模型仍可能偏离姿势、道具或背景，段间接缝也可能跳变。更高步数不是精准迁移保证；未将两分钟长片标为已实测。

Anima客户端、API、工作流和指令模板在包内；「出图词」模型分组界面属于未打包的旧工具，需兼容的`legacy_root`。人物/场景特征自动识图填写尚未实现。检查布局文字存在，不代表图片中的三视图或脸部特写一定合格。
