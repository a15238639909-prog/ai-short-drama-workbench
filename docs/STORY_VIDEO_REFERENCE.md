# 故事视频：多人设全能参考

入口为本机工作台的“故事视频”，地址为 http://127.0.0.1:8853/#story-video 。文生视频、图生视频和全能参考使用同一页面；本次新增全能参考流程，主工作台原“设定→剧本→分镜视频”流程保持原样。

## 输入与操作

1. 选择“全能参考”。每个人物只填人设图、名字、性格、声音描述，可添加或移除；最多七位，为真实末帧预留参考位置。移除人物只取消本次选择，不删除已上传文件。
2. 声音可以选甜美、温柔、清朗、沉稳、活泼、冷静或沙哑，也可填写自定义中文描述。人物年龄、性别、外形依本次图片和故事，不强制成人。声音描述是生成约束，不是声音克隆。
3. 初始场景可不上传，最多一张。场景图只进入第一段视频的参考包，后续各段使用人物图与自己上一段实际采用视频的精确末帧。
4. 已有完整故事时选择“我有完整故事，忠实改编”；只有想法时选择“我提供想法，本地AI先写故事”。名字与性格用于写作，声音描述按稳定人物身份绑定到最终对应台词。
5. 选择2～10段，每段完整15秒及视频比例。自动模式顺序生成到合并；取消自动完成时，先看完整正文和分段规划，确认后再生成视频。

## 本地流程

先识别新素材。完整故事模式保留用户原文；想法模式才调用正式本地小说写作与自审。随后建立原话来源契约，忠实分段，编写中文导演稿，再逐段生成。一个15秒视频内可按剧情切多个镜头，景别服务动作与反应。每段生成后，本地模型观察实际抽帧和真实末帧，下一段导演稿以这些事实续写。

说话人、原话和顺序必须与源正文一致。书写文字不能当对白，不能根据说话顺序猜音色所属人物。对未能确定的发声来源会保留报告并停止，不能由程序猜补。

每段每次明确生成仅提交一次H3，不因一般画面或ASR质量问题自动补拍。可选审稿和画面观察报告的格式、空输出或长度截断，会有证据地记录为不可用后继续，不伪造通过；观察不可用时当前状态记为未知，继续使用实际末帧。语音识别缺少能力或报告不可用也只记录提醒，不预先拒绝生成；真实视频缺失、音轨处理失败、必需的写作或视频生成服务故障、PUBG保护或身份来源冲突仍明确停在断点。导演分镜保留一次局部修订，修订格式仍不可用时沿用上一份已验证的有效稿件。暂停、继续和失败恢复复用已有缓存和原片；用户主动选择重做时使用新take，旧视频保留。
