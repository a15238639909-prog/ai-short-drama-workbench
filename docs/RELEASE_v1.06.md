# v1.06 完整版：发布、验收与恢复

固定标签：`v1.06-complete-20261014`。本版基于v1.05，公开程序、通用模板、预设、工作流、测试和启动工具。

## 本次行为

千问根据一句话故事写正文，后续人物、台词和画面依据保存的正文。单话与逐话模式不再反复回审故事目标或调用模型二次确认说话人。身份不明确时保留原声音称呼，不凭空创建具体人物。

长对白在保留全部文字的前提下按片段时长拆分；没有标点也能分段。文字回复截断时扩大输出额度，次数和总额度仍有上限；分镜或提示词格式反复失败时以当前原文保底，保留对白编号、文字和顺序。没有把残缺JSON当成完整回复。

群体根据正文的实际行动或集体发声建立。具名成员复用个人参考，未具名群体使用多人同框设定。人数未知时不编造精确人数，部分具名成员不冒充整个群体。每段参考采用当前时刻的成员记录和统一图片顺序，保存的老卡与老图保持。

可选的状态接续图片无法取得或参考位置已满时，继续使用文字状态衔接。实际必要图片、视频有效性、成片完整性、用户取消和既有角色规则继续执行。
