# 动作迁移与Anima使用说明（v1.03）

## 动作迁移：上传后自动分段与拼合

入口：工作台左侧「动作迁移」。这是独立工具，不重写故事、人物卡或剧本。

1. 上传原视频：MP4、MOV、MKV或WebM，至少4秒，上限250MB。
2. 上传替换人物图：PNG、JPG或WebP，上限20MB。建议单人完整全身图；四格设定图可选「取最左侧人物」。
3. 写一句人物特征，例如「棕色低马尾，白色高领上衣、黑色长裙和黑靴」。
4. 可选上传场景图并写一句环境特征。不上传则要求保留原场景。
5. 选择整段或指定片段，点击「开始生成对比视频」。默认V1参考流程、0.4档、10步。

动作、运镜和时间顺序参考原视频；人物与场景说明用于补充照片。暂时不会自动识别图片填写特征。高级设置可直接填完整提示词，填写后优先使用；长视频的固定时长表述可能与尾段不符，通常建议留空。

系统把输入统一为24fps，每124帧（约5.17秒）生成一段，再按原顺序拼合。尾段可以借用前一小段作模型参考，交付时只保留新帧。20秒、60秒、120秒分别约4、12、24段，处理时间随段数增加。

结果包括替换后的完整视频、左原片右替换后的对比，两者都保留原视频对应区间的声音；没有原声音轨时保持无声。模型生成的音轨不会替代原声。文件保存在工作台`outputs/motion/`，上传文件在`outputs/motion_uploads/`；清除网页选择不会删除文件。

这不是逐帧精确编辑工具。即使增加采样步数，也不能保证动作、手脚、道具、服装、背景和接缝完全稳定。已完成约14.67秒、15.25秒、23秒的实测；23秒25步版对比10步版没有得到用户确认的明显改善，因此默认仍为10步。

每段结果独立保存。不要把旧15秒分段任务的检查点用于新124帧方案；旧结果不受影响，需要处理时新建任务。当前页面提供开始、停止和结果查看，不能据此承诺所有中断状态都有一键恢复入口。

## Anima：独立接口，不接管自动创作

当前公开源码包含：

- `models/anima_client.py`：英文提示词与独立出图客户端。
- `models/anima_workflow.json`：对应ComfyUI工作流，不包含模型权重。
- `presets/instructions/Anima_英文词组.txt`：普通插画、场景等英文标签指令。
- `presets/instructions/Anima_人物三视图.txt`：三视图及可选面部特写指令。
- 设置页可编辑上述指令；年龄保护和模型运行检查继续生效。

自动故事的人物图、场景图仍沿用Krea2。Anima不是自动替换主模型的开关。

v1.03已附带「出图词」完整界面：打开左侧出图词，选择Krea2或Anima，选择该模型的预设，填写需求后生成提示词，再点击出图。切换模型时预设和草稿分别保存；Anima提供英文词组、人物三视图及面部特写模板。`legacy_root`留空即可加载内置界面，无需旧版工作台。开发者也可调用以下接口。

| 接口 | 用途与主要字段 |
| --- | --- |
| `GET /api/image/anima/config` | 读取默认英文词组主指令 |
| `POST /api/image/anima/prompt` | `text`为需求，`system`为可选自定义指令；调用本地写作模型整理英文词组 |
| `POST /api/image/generate` | `model: "anima"`、`text`为英文提示词，另可传`base_w`、`base_h`和`seed`；实际调用本地ComfyUI出图 |

使用前核对工作流中的模型名称和节点已安装。Anima使用英文逗号词组；自动提示词会整理换行和重复标签，手写提示词不自动改写。人物板由模型生成，代码检查布局描述齐全不代表图中三视图一定合格。

本机工作台无公网鉴权，请只在自己的电脑使用这些接口。修改预设前自行备份；GitHub更新不会自动覆盖用户安装目录。
