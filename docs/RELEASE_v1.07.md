# v1.07｜本地故事视频、人设图调整与四世界服装扩充

本版新增本地故事视频入口，分开故事确认与成片生成；同时调整人设图的故事设定优先级，扩充服装库，并补齐拖图、成品查找与任务控制。

## 本地故事视频

- 首图模式：上传或拖入一张图，填写故事方向，先生成完整分段故事和本地AI审阅建议；确认故事后再生成成片。
- 纯文字模式：先生成分段故事与第一段预览；确认后继续延伸，复用第一段的真实末帧，不重复生成第一段。
- 新任务默认每段完整15秒，默认10段约150秒；动作安排和电影提示词覆盖完整时长，使用完整段尾的真实末帧续接。原生帧数对齐可能多出少量帧，已有任务沿用创建时的时长与结果。
- 审阅结果作为建议，不因未通过而阻断生成，也不自动改写故事或裁短视频。可手动重做所选段，该段及后续按新末帧重新生成，旧故事和视频版本保留；模型缺失、格式错误及资源保护仍会报告实际错误。
- 首图模式跟随图片画幅；纯文字支持16:9、9:16、1:1、4:5、3:4，默认16:9。生成尺寸按H3原生网格调整，首段、续段与成片沿用同一比例。
- 故事创作、视觉观察和生成使用本机Qwen与H3，无云端模型回退；每次模型调用检查PUBG，并保留显卡互斥和内存保护。当前为10步预览流程，不承诺2K成片或中文口型效果。

## 人设图与服装

- 首图保留故事人物原有文字设定，不把自动身材标签扩写为额外身高、比例、骨架、脂肪或肌肉参数。填写明确身高或手动覆盖比例、身材后，再加入对应要求；只改姓名或发型不会启用体型覆盖。
- 新增身高输入与保存支持；修改或清空身高、手动比例或身材后，旧提示词失效，后续重新生成采用当前要求，保留原有图片版本。
- 人设图读取项目已保存的画风，批量资产记录同步所选画风，修正默认误标为写实的问题；画风用于表现形式和质感，不作为改变人物体貌的依据。
- 东方、西方、未来、现代各新增40套服装，共新增160套。四世界当前可选合计194套：东方48、西方50、未来48、现代48。补充职业、身份、场合、季节、材料和结构差异，保留所有原有条目及其他旧世界库。
- 修复四世界名称与服装库旧键的对应关系，使下拉选项能取回完整描述；故事已明确指定的穿搭继续保留。

## 拖图、成品与任务控制

- 统一图片拖入处理，覆盖故事视频、动作迁移、素材卡片及嵌入兼容工具；支持本地文件、工作台已有图片，以及网页HTML、URL和浏览器data/blob图片。支持20MB内PNG、JPG、WebP；网页导入受原网站权限、防盗链和网络条件限制，全离线使用请拖入本地文件。
- 素材历史新增“成品”筛选，汇总主流程合成、视频拼接、故事视频及动作迁移结果，包含保留的历史成片版本，排除中间片段与对比视频；读取现有记录，不移动原文件。
- 动作迁移按参考视频画幅计算H3原生尺寸，补充千问输出截断、空白正文、仅思考内容及限制返回的诊断信息；已有分段保留，上传中断的文件也保留供检查。
- 任务条按当前显示的任务执行暂停、继续和取消，等待故事确认时可直接返回查看故事；操作失败显示错误。保留暂停、取消和等待确认状态，避免结束处理将其误记为完成。
- 已结束的失败、取消或等待提示可关闭；关闭记录在刷新后保留，新一轮任务或其他项目的提示仍会正常显示。
- 本地千问端口可通过`V41_QWEN_PORT`统一配置，客户端启动与显卡占用管理使用同一端口。
