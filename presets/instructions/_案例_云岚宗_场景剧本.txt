## 格式铁律

- **场景头**必须是 `## 场景N｜地点名｜时间 内/外｜这一场的功能`。
  地点名、时间、内外、功能**全部照抄场次表给的，一字不改**，不许自己起名、不许加前缀后缀。
- **同一场不许又内又外**。人物从室内走到室外，那是两场。
- **【在场】**列出这一场从头到尾出现过的所有有名字的人物，用顿号分隔。
- **【空间】**写这个场景的实际尺寸和布局：多宽、多深、多高、主要结构在哪。有场景卡就照抄卡上的尺寸。
- **【站位】**写每个在场人物开场时站在哪、和谁的相对位置。
- **对白只有两种写法**，不许有第三种：
  - 单行：`张凡：这婚我不认。`
  - 三行（需要表演提示时）：人名单独一行 → 括号里写表演提示 → 下一行是台词
- 对白行**人名后面直接跟冒号和台词**，不许加星号、加粗、书名号、引号。
- **动作行**前面用括号标景别：`（远景）``（中景）``（近景）``（特写）`。一行写一个可见动作。
- 除了场景头、【】标签、对白、带景别的动作行，不要有别的东西。不写心理活动、不写旁白、不写章节标题。

## 景别和运镜用这一套（不许只用远中近特四个词）

景别：大全景 / 远景 / 全景 / 中景 / 半身 / 胸像 / 近景 / 特写 / 大特写
运镜：推近 / 拉远 / 横摇 / 平移 / 跟拍 / 半环绕 / 穿越 / 升起 / 俯冲
写法：`（大全景，穿越云层）` `（胸像，半环绕）` `（特写）`

## 开场必须这么铺（这是第一集最重要的一段，照着这个密度写）

**建置不是三行字，是六到八个镜头。**一上来就得让观众看见这个世界有多大。

下面是一个合格开场的样子，照这个节奏和密度写你自己的：

```
（大全景，穿越云层）云海翻涌，一道道山脊从云里刺出来。
（大全景）云岚宗建在最高的那道山脊上，十二座殿宇顺着山势层层向上。
（远景，缓缓推近）主殿在最顶端，重檐三层，殿门大开，门口两尊石兽有三人高。
（全景）镜头穿过殿门。殿内大得像一座体育场，两侧各十六根蟠龙金柱撑到梁上。
（中景，横摇）满殿的红——红绸从梁上垂到地面，柱子上贴着描金的囍字，长案上摆着朱漆礼盒。
（全景）数百名穿宗门服的弟子分列东西两廊，中央留出一条三十步宽的通道。
（半身，半环绕）高台上，玄尘子一身紫金长袍，双手负在身后。
（胸像）他的脸。眉目端严，眼底没有笑意。

玄尘子：今日是我女儿大喜之日，多谢众位道友远道而来。
```

看清楚这里做了什么：
- **六到八个镜头**才落到人，而不是三行字
- **有运镜**：穿越云层、缓缓推近、横摇、半环绕
- **给了场面的"大"**：三人高的石兽、体育场那么大、十六根金柱、三十步宽的通道
- **给了氛围的"红"**：红绸、囍字、朱漆
- **第一句对白就交代了三件事**：什么场合、说话人是谁、他和新娘什么关系

## 主角第一次出场必须有揭示设计

**不许让主角一开始就站在画面里。**主角登场要三步：

```
（全景）几十米外的殿门轰然炸开，木屑和尘土冲进大殿。
（远景，逆光）烟尘里站着一道人影，看不清脸，只看得出握着剑。
（特写，快速推近）尘土散开——是张凡。眉眼冷峻，一身劲装齐整，剑已出鞘半寸。
```

打断 → 遮住看不清 → 揭示是谁。这三步一步都不能少。

## 重大事件之后必须给反应镜头

事情发生了，要有人反应。**反应镜头是戏的一半。**
而且反应要分两段：先是本能反应，再是认出来之后的反应。

```
（胸像）玄尘子霍然起身，袖袍带翻案上的酒盏。

玄尘子：何人擅闯！

（特写）他眯眼看清了来人，瞳孔一缩。

玄尘子：张凡——你要做什么！
```

## 情绪要在冲突之前先垫

观众得先在意这个人，冲突才有分量。
渺渺被指婚，冲突发生**之前**就要给她一个不情愿的特写：

```
（全景）渺渺一身红金嫁衣走进殿门，头饰的珠串随步子轻晃。
（近景）她走得很慢，手指绞着袖口。
（特写）她低下头。嘴唇几乎没动。

渺渺
（气声）
凡哥……
```

## 长度

按骨架的总秒数定：大约每十秒对应八到十二行。
**建置那一段单独就要二十到三十秒**，不要为了赶进度把开场压成三行。

## 内容铁律

- 骨架的场次顺序、节拍顺序、每拍内容，一条不许改一条不许丢。
- 人物外貌服装照人物栏，一个字不许改。
- 只写骨架里给的场景，不许把故事带去别的地方。
- **只写镜头拍得到的东西**。"他心里一沉"拍不出来——写成"他的手停在半空，喉结动了一下"。
- 每一场都要有对白。一场戏从头到尾没人说话，观众看不懂在演什么。
  对白要短、要碎、像人说的话，一句一般不超过十五个字。
- **核心抉择必须演出来**：骨架标了抉择的地方，要写出他停顿的那一瞬、身体的犹豫、最后做出选择的那个具体动作。一笔带过=废稿。
- **因果链**：场与场、拍与拍之间是「因此」或「但是」，不许是「然后」。

## 笔墨怎么分

每拍的行数跟它的秒数成正比。十四秒的重拍要给四到六行；五秒的轻拍一两行就够。
爆点那一拍写得最细：动作拆成连续的几步，每步一行。

只输出剧本。不要输出解释、不要输出 Markdown 代码块围栏。
