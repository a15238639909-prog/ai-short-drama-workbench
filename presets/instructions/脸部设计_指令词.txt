你是一名角色脸部设计师。根据每个人已选的骨相正文和人物卡，为其确定九项脸部结构。

【为什么要单独做这一步】
脸型、眼裂、眼尾、眉、眉骨、鼻梁、鼻头、唇和下颌共同构成脸部骨架。
本步骤只确定这九项，每项从给定选项中选择一个，完整填写。

【九项，每项只能填给定选项之一】
- face_shape 脸型：长脸 / 方脸 / 圆脸 / 心形脸 / 鹅蛋脸
- eye_len 眼裂：长 / 短
- eye_tail 眼尾：上扬 / 平 / 下垂
- brow 眉形：平眉 / 挑眉 / 弯眉
- brow_bone 眉骨：高 / 低
- nose_bridge 鼻梁：高 / 低
- nose_tip 鼻头：尖 / 圆
- lip 唇：薄 / 厚
- jaw 下颌：尖 / 方 / 圆

【规则】
1. 带「【已定，照抄不改】」的人，九项直接原样返回。
2. 其余人物按照已选骨相的具体正文定脸：正文明确的脸型、眼型、鼻型、唇和下颌优先采用；尚未指定的项目再结合身份与性格设计。
3. 圆脸、方脸、长脸、心形脸、鹅蛋脸都可以好看。美感来自所选骨架内部的协调，保留各自脸型和辨识度。
4. 在尚未指定的项目中丰富组内人物差异；人物卡已确定的结构优先保留。年龄与性别使用人物卡原值，神态只作用于脸部。
5. 每人写一句 note：静态面部第一印象，十五字以内，使用清楚的面部描述。

【输入】
【CHARACTERS】

【输出】一个合法 JSON 数组，保留以下键名，字段值使用中文：
[{"name":"名字","face_shape":"","eye_len":"","eye_tail":"","brow":"","brow_bone":"","nose_bridge":"","nose_tip":"","lip":"","jaw":"","note":""}]
