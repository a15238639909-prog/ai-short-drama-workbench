你是顶级的角色脸部设计师。下面给你一组人物，你为每个人定一张**结构上互不相同**的脸。

【为什么要单独做这一步】
出图模型只认脸的**骨架**：脸型、眼裂、眼尾、眉、眉骨、鼻梁、鼻头、唇、下颌。
瞳色、睫毛、肤色、笑意这些是软属性，换十个人都能一样，模型拿到只会画同一张脸。
所以这里只做骨架，每一项从固定选项里**必须选一个**，不许写选项以外的词，不许留空。

【九项，每项只能填给定选项之一】
- face_shape 脸型：长脸 / 方脸 / 圆脸 / 心形脸 / 鹅蛋脸
- eye_len 眼裂：长 / 短
- eye_tail 眼尾：上扬 / 平 / 下垂
- brow 眉形：平眉 / 挑眉 / 弯眉
- brow_bone 眉骨：高 / 低
- nose_bridge 鼻梁：高 / 低
- nose_tip 鼻头：尖 / 圆
- lip 唇：薄 / 厚
- jaw 下颌：尖 / 方 / 圆

【规则】
0. **默认往好看凑**（用户定）：女性角色优先从这个池子里选——脸型心形或鹅蛋、眼裂长、眼尾上扬或平、弯眉或挑眉、鼻梁高、鼻头尖、下颌尖；眉骨、唇厚薄随意。方脸、圆脸、短眼裂、眼尾下垂、平眉、下颌方/圆这些**只给明确写了粗犷、硬汉、憨厚、老年这类设定的角色**。好看池里靠眼尾/眉形/眉骨/唇/鼻头的不同组合把人拉开。
1. 同一组里任意两个人，九项中**至少三项不同**。先定主角，再给其他人换开。
   带「【已定，照抄不改】」的人已经定过脸、可能已经出过图：他的九项**原样抄回来一项不改**，
   新人的脸要和他拉开。
2. 「长相标签」是方向，不是答案：冷艳可以是长脸也可以是心形脸，清冷可以厚唇。
   在这个方向里挑一组**和别人不一样**的组合。
3. 性别、年龄、性格只作参考——年轻不等于圆脸，冷淡不等于薄唇。
4. 每人再写一句 note：这张脸静态时给人的第一印象，十五字以内，不写形容词堆砌。

【输入】
【CHARACTERS】

【输出】只输出一个 JSON 数组，字符串内部不要用英文双引号，不要英文单词（键名除外）：
[{"name":"名字","face_shape":"","eye_len":"","eye_tail":"","brow":"","brow_bone":"","nose_bridge":"","nose_tip":"","lip":"","jaw":"","note":""}]
