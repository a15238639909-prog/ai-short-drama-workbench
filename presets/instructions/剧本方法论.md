# 剧本方法论（题材引擎库）

骨架和正文指令引用这个文件。**结构跟着当前话的真实矛盾走，不套统一公式。**

## 使用优先级

- 用户明确写出的事件、人物、地点、结尾、画面与镜头设想永远最高优先级。
- 已锁定事实、当前话剧情真相、人物卡和场景卡次之。
- 题材引擎只负责节拍快慢、张力来源和笔墨比例，不能覆盖或改写上述事实。
- 混合题材选择一个主引擎；其他引擎只在确实适合的场次局部辅助，不能十套方法同时生效。
- 设定聚焦在一个场景一个事件时，就写一场；真实发生地点移动时才换场，不许为了公式扩场或缩场。

## 引擎一：感官特写型

一个人、一个瞬间、一次"被看见"。没有冲突，没有目标受阻。张力全部来自**期待管理**：观众知道要发生什么（风、裙摆），你让它慢慢来。

节拍形状（以 120 秒为例）：
1. **入画**（~15%）：空间先立住——声音、光、街的质感。她从远处进入，还看不清细节。
2. **细节堆叠**（~30%）：视线一段一段地占有她——脚踝的蹬踏、裙摆的摆动节奏、腰身、
   座垫上臀部的起伏、发丝、锁骨。每个局部单独给足笔墨，顺序从远到近、从下到上。
   **堆叠就是铺垫**：裙摆每一次普通的摆动，都在为爆点存钱。
3. **爆点**（~20%）：那一阵风。时间放慢写——风从哪来、布料怎么抬起来、露出什么、
   颜色形状轮廓、贴着哪里。一个两秒的瞬间用全篇最密的笔墨。
4. **对视**（~20%）：她察觉他的目光。回望。不躲闪。这是这个题材里唯一的"事件"。
5. **余韵**（~15%）：她骑远，裙摆落回去，街道恢复原样。他站在原地。留白收尾。

写作要点：
- 全程单一视点（谁在看，就从谁的目光写）
- 爆点只有一个，其余高光都比它低半档，不许两个爆点抢戏
- 不要金句对白。这个题材里对白越少越好，一句都没有也行

## 引擎二：剧情冲突型

有人想要什么，有东西挡着。用欲望-障碍-转折-代价。节拍形状：建立欲望 → 第一次受阻 →
升级 → 转折 → 结果。适用：悬疑、争执、追逐、任务。

## 引擎三：关系推进型

两个人从状态 A 到状态 B（陌生→吸引，亲密→破裂）。张力来自距离的变化速度：
每一步靠近都要有一次犹豫或停顿垫底，直给就没戏了。节拍形状：距离确立 → 第一次试探 →
退半步 → 再进一步 → 新距离定格。

## 通用铁律（所有引擎）

- 设定里明写的事件一个不丢、顺序不改；只补因果成立所必需的最少过渡，不凭空扩写支线或地点
- 内容配比是笔墨分配的法律（感官占八成时，叙事只做串场）
- 用画面写不用总结写；每个高光落到具体的身体部位、布料、光线、动作瞬间
- 时长权重：爆点/高潮所在的节拍拿最多秒数

## 引擎四：打斗型（仙侠大决斗用）

来自实战模板「动作导演 Pro」「一图成战」的硬规则：
- **首帧即动作**：开场禁止站立、凝视、呼吸、慢推镜、纯聚势。第一镜直接启动有效动作。
- 15 秒 ≈ 4 镜；动作母题先用 4~6 个**连续具体动词**定下来（拔剑→格挡→拧身横斩→刺穿），
  再拆镜头。招式由"角色身份 + 场景条件"推导，不套通用招。
- **运动链不断**：高潮构图里必须始终有可见的运动（主体、介质、镜头至少一样在动），
  禁止全画面同时静止。
- 力量感靠五件事共同表达：镜头运动、主体运动、介质运动（雨/尘/碎石/衣摆）、
  物理反馈（击退/碎裂/溅落）、声音。每镜都要有介质和反馈。
- 节拍形状：开战宣告 → first blood → 互换攻防升级 → 大招高潮 → 收势定格。

## 引擎五：悬疑压迫型（黑暗系悬疑用）

张力来自**信息差**：观众比角色多知道一点，或者少知道一点，不能持平。
- 节拍形状：日常表象 → 异常细节入画（观众先看见）→ 角色察觉 → 调查/接近 →
  真相半掀（新的更大疑问收尾）。
- 镜头语法：长镜头慢节奏为主，切镜少而重；异常细节用"藏在画面角落"而不是特写强调；
  声音先于画面（先听见，再看见）。
- 光线是叙事的一半：光源少、方向硬、阴影里永远有画面信息。
- 禁止 jump scare 式的无因惊吓；每次惊吓都要有前置铺垫。

## 引擎六：群像喜剧型（多人抢一人 / 后宫日常 / 轻喜剧用）

张力**不是**来自"会不会在一起"，而是来自**同一个欲望被几个人用完全不同的方式表达**。
这是群像戏和双人戏的根本区别：双人戏看距离变化，群像戏看**手段对比**。
写成"两个人暧昧、其他人围观"就彻底错了。

节拍形状（以 120 秒为例）：
1. **常态入画**（~10%）：几个人在同一个空间里做同一件事（赶路、吃饭、干活）。
   先把"他们本来就在一起"立住，不要一上来就抢。
2. **第一轮出手**（~30%）：A 用她的方式接近目标。**必须是可见的身体动作**，不是心理活动。
   目标人物给出一个不带偏向的反应（这很重要：他不能选边，一选边喜剧就塌了）。
3. **连锁反击**（~30%）：B 用**完全不同的**方式打断 A，C 再用**第三种**方式打断 B。
   三个人的手段必须互不重样——一个用话术、一个用蛮力、一个耍赖，各占一路。
4. **目标人物踩雷**（~20%）：他说了或做了一件本来无辜的事，结果同时得罪或同时取悦所有人。
   全场安静一拍，所有人一起看向他。**这是这个题材唯一的"事件"。**
5. **悬而未决**（~10%）：没有人赢。局面回到常态，但欠着一笔账，留到下一场。

写作要点：
- **一人一路，绝不重样**：给每个角色分配一种固定手段（话术型／蛮力型／耍赖型／沉默型），
  整部作品里不许换。观众认人靠的就是这个，不是靠长相。
- **目标人物永远不选边**。他一旦明确偏向谁，另外几个就失去动机，戏当场死。
  他的标准反应是"后知后觉"或"想息事宁人反而火上浇油"。
- **对白极短**，一到两句就换人。三句以上的台词在这个题材里一定是废话。
- **喜剧机制每场只用一个**，不要在一场里同时玩争位置、争食物、争时间。
- **不要写"心里酸溜溜"这种**。吃醋要落到动作上：把最大的一块肉拨走、突然拍一下背、
  用魔法飞过来抱住手臂。

镜头语法：
- 群像镜为主，**画面里同时有两个以上的人**，不要频繁切单人特写——切碎了就看不出对比。
- 每一轮出手给一个"其他人的反应镜"，反应镜比动作镜更好笑。
- 第 4 拍那个"全场安静"必须给一个**全员同框**的镜头，这是包袱落地的地方。

## 引擎七：爽点打脸型（逆袭 / 扮猪吃虎 / 开挂爽文用）

张力来自**认知差的兑现**：观众和主角知道真相，场上的人不知道。爽感 = 憋屈的时间 × 反转的干脆。
最常见的失败是**憋屈不够**：铺垫两句就翻盘，一点不爽。

节拍形状（以 120 秒为例）：
1. **压制**（~35%）：对方居高临下，主角被明确地看轻、羞辱或拒绝。
   **这一段必须给足**，是全篇最长的一拍。要具体到台词和动作，不能一句"他被嘲笑了"带过。
2. **摊牌前一秒**（~10%）：出现一个不可回避的当场检验——比赛开始、货物拆封、
   身份被念出来。**必须是外部事件逼出来的**，不能是主角自己想通了。
3. **反转**（~20%）：真相当众落地。**只用一个动作或一句话完成**，
   不许解释、不许回忆、不许旁白说明。
4. **打脸**（~25%）：镜头给**看轻他的人**的反应，不是给主角。爽感在他们脸上，不在他身上。
   一个个来，从最嚣张的那个开始。
5. **离场**（~10%）：主角不解释、不得意、直接走或继续做本来在做的事。
   **越平淡越爽**。回头补一句狠话是三流写法。

写作要点：
- **憋屈段的长度是爽感的本金**，不要为了快进砍它。
- 主角在压制段**不许反驳**。他一还嘴，观众的期待就被提前花掉了。
- 反转的证据必须**在压制段就露过一眼**（观众看得见、场上人忽略了），否则是硬开挂。
- 打脸段的重点是**反应镜**：瞳孔、后退半步、手里的东西掉了、说到一半卡住。
- **主角开挂时，世界不许跟着变好**。周围人的处境该多糟还是多糟，
  爽感来自对比，把整个环境一起拉高等于把爽点抹掉。

镜头语法：
- 压制段用**仰角拍对方、俯角拍主角**；反转那一拍**机位对调**，这是最直接的视觉爽点。
- 反转瞬间可以定格或降速，但**只降一次**，多了就廉价。
- 打脸段快切反应镜，每个人只给 1~2 秒。

## 引擎八：生存压迫型（末日求生 / 资源匮乏 / 灾后用）

张力来自**每一个选择都有代价**：没有免费的东西，拿了这个就没有那个。
不是打怪，是算账。写成"打丧尸"就变成打斗型了，不是这个引擎。

节拍形状（以 120 秒为例）：
1. **匮乏立住**（~20%）：先让观众看见"少"——水只剩半瓶、子弹数得清、
   罐头上的日期。**用具体数量和实物，不要用形容词。**
2. **必须出门的理由**（~15%）：某样东西没了，不出去就撑不过去。理由要具体到物件。
3. **代价浮现**（~30%）：路上出现选择：走近路要冒险，走远路要多花半天；
   救那个人要分掉自己的补给。**每个选项都真的有损失**，不许有白捡的好处。
4. **付出代价**（~25%）：他做了选择，代价当场兑现——受伤、丢东西、暴露位置、失去同伴信任。
   **代价必须可见**，不能是"心里留下阴影"。
5. **微小的结余**（~10%）：拿到了要的东西，但比出门时少了别的。收在一个具体的清点动作上。

写作要点：
- **数量就是台词**。"还有三发子弹"比"弹药不多了"有力十倍。
- **不许有白给的资源**。捡到东西必须伴随一个损失或一个新麻烦。
- 环境的破败是底色，**不因主角而改变**。主角有金手指时，他的富足要用
  周围人的匮乏反衬——别人在数子弹，他随手扔掉一箱，这才叫爽。
- 反派往往不是怪物，是**同样缺东西的人**。
- 不要写"末日很惨"，写"这瓶水该给谁"。

镜头语法：
- 大量**实物特写**：手里的东西、包里的东西、地上的东西。物件就是剧情。
- 空间用**遮挡和纵深**组织，永远有看不见的地方，危险来自画外。
- 光源少、可数（手电、火堆、天光），不要打亮全场。

## 引擎九：成长蜕变型（拜师 / 修炼 / 突破 / 觉醒用）

张力来自**旧方法失效**：他一直靠的那一套，这次不管用了。
最常见的失败是"苦练→变强"的流水账——那不是戏，那是履历。

节拍形状（以 120 秒为例）：
1. **用旧办法**（~20%）：他用一直以来最拿手的方式去解决问题。
2. **旧办法失灵**（~20%）：不是打不过，是**方式本身不对**。要让他吃惊，不只是吃亏。
3. **看见新东西**（~20%）：一个示范、一句点破、一个偶然的现象。
   **必须是可见的**——别人的一个动作、水的一个流向，不能是"他悟了"。
4. **笨拙地试**（~25%）：第一次用新方式，做得很难看，甚至更糟。**这一拍不能跳过**，
   直接学会就没有成长可言了。
5. **成了一次**（~15%）：只成一次，只解决眼前这一个问题。不要一步登天。

写作要点：
- **旧方法必须先被认真展示**，观众得知道他原来靠什么吃饭，失灵才有分量。
- 顿悟的来源必须**在画面里**，不能在脑子里。
- 笨拙那一拍是这个引擎的灵魂，**越丢人越好**。
- 结尾**不要总结感悟**。成了就是成了，让观众自己看出来。

镜头语法：
- 旧办法和新办法要用**同一个机位、同一个景别**拍两次，让观众直接对比。
- 笨拙段用长镜头不切，尴尬是靠时间堆出来的。
- 成功那一下反而可以短，一个干脆的镜头收掉。

## 引擎十：情感虐心型（误会 / 牺牲 / 离别 / 错过用）

张力来自**观众知道、当事人不知道**：观众看得见那份心意，场上的人看不见。
不是让人物哭，是让观众替他们着急。角色越克制，观众越难受。

节拍形状（以 120 秒为例）：
1. **温度确立**（~20%）：先给一段好的。**必须真的好**——有笑、有靠近、有具体的小事。
   没有这一段，后面的失去不值钱。
2. **信息错位**（~20%）：一方做了一件事，另一方**看到了结果没看到原因**。
   观众两边都看得见。
3. **误解生效**（~25%）：因为这个错位，他们做出了伤害对方的选择。
   **两个人都是对的**，这才叫虐；有一方是坏人就变成冲突型了。
4. **最近的一次错过**（~25%）：差一点就说破——话到嘴边被打断、
   信写好了没送出去、转身晚了半秒。**必须是外部原因打断**，不是自己不肯说。
5. **各自离开**（~10%）：两人分开，各自做一个很小的动作暴露真心（观众看得见，对方看不见）。

写作要点：
- **不要让人物解释**。一解释就完了。
- **两边都要给动机**，谁都不是坏人。
- 眼泪要省着用，全篇最多一次，而且不给正脸。
- 越是想说的话，越要用动作代替：把伞留下、把那件衣服叠好、把名字划掉又写回去。
- **物件承载感情**：一个来回出现的东西，比一百句台词管用。

镜头语法：
- 大量**背影、侧脸、隔着东西拍**（门、玻璃、人群）——距离感就是主题。
- 错过那一拍用**同一画面里两个人反方向运动**，一个镜头讲完。
- 收尾留白，最后一镜停在空场景上，让人物走出画面。
