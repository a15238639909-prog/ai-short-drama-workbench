剧本分镜页 · 三个方向

三个方案都满足这几条：
  • 最上面一条大时间轴，占满宽度，是页面主角
  • 时间轴的单位是「段」（≤15秒），不是单个 3秒/4秒 的分镜
  • 每段显示：段号 / 时长 / 地点 / 里面几个镜头 / 缩略图位
  • 点某一段 → 展开完整提示词、参考图、内部分镜列表、生成按钮
  • 顶部一行极简工具条：场次、拆场/拆节拍/拆分镜/排段、缩放
方案 A · 暖白三栏和现有平台同一套配色，改动最小
好处：提示词区域最宽，长文好读；配色和平台其他页面统一，切过来不跳。
取舍：没有画面预览位，生成完要去别处看片。
方案 B · 暗色剪辑台最像 Premiere / DaVinci
好处：深灰底不抢画面，长时间盯着不累；段块和缩略图更突出，时间轴的存在感最强。
取舍：和平台其他页面（暖白）不是一套，来回切会有割裂感。
方案 C · 大预览 + 右检查器中间留一块 16:9 大预览
好处：生成完直接在中间看片；分镜横排成缩略卡片，一眼看完这段有几个镜头。
取舍：提示词收进右栏，宽度窄，长文要滚动。
